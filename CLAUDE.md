# Project: Samsara

- Ignore the `_trash/` and `_unsorted/` folders when searching.
- The user writes in Vietnamese; reply in Vietnamese. In-game text in the mod is also Vietnamese.
- In-game text lives in `mod/src/main/resources/assets/samsara/lang/vi_vn.json` (use `Text.translatable`, or `I18n.translate` on the client when a `String` is needed). Do not create `en_us.json` in src: `build.gradle` generates it as a copy of `vi_vn.json`. Write a literal percent sign as `%%`. Debug command output may stay as literals.

## Layout
- `mod/` — Fabric mod (Minecraft 1.20.1, Java 17 target, Fabric Loader 0.15.11, Fabric API 0.92.2).
- `shader/Samsara-Cosmic-Shaders/` — the project's Iris shaderpack (VHS camcorder look).
- `scripts/master_production_document_project_samsara_revision.md` — the story doc: core lore and mechanics with the stage table (top section, e.g. stage 4 on the 7th sleep), detailed scene-by-scene script for Videos 1–9 with the verbatim `<System>` dialogue, Channy outro and the Chu Kỳ #2 epilogue. Treat it as the source of truth for story and progression. It is ~4000 lines: search by heading (`# VIDEO n`, `# PHẦN`) and read only what you need. The original doc it replaced is in `_trash/scripts_old/`.
- `scripts/hien_trang_trong_mod.md` — what the mod has built, written as story. Update it whenever player-facing content changes. `scripts/yeu_cau_cho_mod.md` — approved script changes waiting to be built in the mod.
- `HANDOFF.md` — current implementation status, code map, test commands and decisions that override the design doc (7th sleep goes to Nam's sunflower memory first; Elysian Highlands and the mirror ritual were removed). Read it before working on gameplay.
- `start_samsara.bat` — one-click build + dev client launcher (log: `mod/run/samsara_client.log`).

## Build
- There is no Gradle wrapper. Use the cached Gradle 8.6 with JDK 21 (the system `java` is Java 8 and will not work):
  ```bash
  cd /d/c/mod && export JAVA_HOME="/c/Program Files/Zulu/zulu-21" && G=$(ls -d ~/.gradle/wrapper/dists/gradle-8.6-bin/*/gradle-8.6 | head -1) && "$G/bin/gradle" build --console=plain
  ```
- Output jar: `mod/build/libs/project-samsara-1.0.0.jar`.

## Run the dev client
- Same command with `runClient` instead of `build`. Run it in the background, redirect output to a log file, and wait for `Sound engine started` (ready), `Crash` or `Stopping!` (closed). It takes about 30–60 s.
- Do not launch a second client while one is open. If only resources (textures, JSON) changed, rebuild and tell the user to press F3+T in game.
- Iris and Sodium jars live in `mod/run/mods/`. `mod/run/shaderpacks/Samsara-Cosmic-Shaders` is a junction to `shader/Samsara-Cosmic-Shaders`, so shader edits apply directly.
- `build.gradle` passes `-Dsodium.checks.issue2561=false` to `runClient` only: Loom's dev LWJGL (3.3.2-snapshot) otherwise makes Sodium refuse to start. Do not remove it.
- Harmless log noise: "Unable to delete file ... latest.log", Realms authorization failure.

## Testing in game
- Debug commands are `/samsara test <feature>` (see `mod/src/main/java/com/samsara/command/SamsaraTestCommands.java`). Every new feature gets a matching test command; remove the command when the feature is removed.
- Commands need the leading `/`. Without it the text is sent as chat and nothing happens — check the log's `[CHAT]` lines before suspecting a bug.

## Sun / black-hole stages
- `sun_stage1..4.png` are generated by `mod/tools/generate_sun_stages_pixel.py` (pixel art, 128x128 by default via `SUN_RES=2`, premultiplied alpha). Edit the script and regenerate; never hand-edit the PNGs. It also writes `mod/tools/preview_sun_stages.png` for review.
- The premultiplied textures depend on `WorldRendererMixin` drawing the sun with blend `ONE, ONE_MINUS_SRC_ALPHA`. Change both together.
- The black-hole sun is visible only while the camcorder is fully aimed; the naked eye always sees the vanilla sun. Stage 0 = vanilla sun (no sleeps yet).
- The original blurred textures are kept in `mod/tools/sun_stages_old/`.
